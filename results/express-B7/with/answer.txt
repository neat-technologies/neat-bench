**Root cause:** `getUserById` (src/services/user.service.js:36) calls `User.findById(id)`, which makes Mongoose cast `id` to an `ObjectId`. Passing an email string there throws a Mongoose `CastError` for any valid login attempt, which propagates as an uncaught error → Express error handler returns 500 instead of the intended 401 for bad credentials.
