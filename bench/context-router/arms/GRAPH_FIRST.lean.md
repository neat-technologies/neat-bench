## NEAT

This project has NEAT, a live graph of the system's code and runtime. Its MCP tools (`mcp__neat__*`) answer what reading files can't: what actually ran, where a failure began, and what a change will reach.

Use it when the cause isn't where the request points: a failure across services, a symptom with no obvious file, or a change whose reach you need to know. Start with `investigate` for a failure, or `ask` for a plain-language question.

When the request already points at the code, read it and fix it directly.
