# ops

Box-side scripts, governed by `docs/contracts/environment.md` and `docs/contracts/run-validity.md`. Each is streamed to a box and run from there; none runs on a laptop.

- `audit-vs-chart.sh` — read-only. Renders the pinned chart with the release's values and diffs every live `otel-demo` Deployment against it (init containers, probe ports, memory limits, images, node selectors, replicas, env count), and prints the field-manager owners of the suspect fields. The launch gate of run-validity rule 1.
- `fix-kind-bridge.sh` — idempotent. Re-adds the kind docker network's IPv4 gateway to the bridge when a reboot drops it (environment rule 9).
- `recover-20261016.sh` — the 16 October recovery: strips the injector-owned fields with a JSON patch, recycles the pods stuck in Unknown, purges the duplicate demo in `default`, installs the bridge guard, then prints the settled state. Kept as the worked example of a reset that removes what an injector added (ADR-003); `standup-box.sh` and the worker supersede it.
- `standup-sregym.sh` — stands SREGym up on a bench box in phases (`deps`, `wire`, `cluster`, `daemon`, `all`): clone with the applications submodule, `uv sync`, inotify sysctls, the collector patch below, SREGym's own 4-node kind cluster (refuses without 16 GiB free and load under the core count), and a live NEAT daemon over the applications checkout. ADR-006, ADR-007.
- `sregym-collector-neat.py` — patches SREGym's single collector (namespace `observe`, which receives Jaeger and OTLP from every application) to also export to the NEAT daemon and to a capture file. Idempotent; refuses if the upstream file's shape changed.
- `sregym-smoke-deploy.py` — runs SREGym's own Conductor up to `deploy_app()` for the application a problem id names: observability stack, the patched collector, the application and its default workload. No agent, no fault, no oracle. The smoke path, never a bench run.
- `sregym-capture.py` — pulls the collector's span capture and splits it per service with the language detected from the application checkout: the deliverable Instrumentation files coverage gaps against.
- `sregym-span-keys.py` — per span kind, the attribute keys that survive on a captured service's spans. Tells a Jaeger-native app's ingest floor from a join rule: whether `rpc.*`, `http.*`, `peer.service` or `server.address` arrive after the collector's conversion, or only opentracing tags.
- `sregym-repoint.sh` — installs a published NEAT version, restarts the daemon over the source workspace, and re-captures every deployed application with the fusion delta per service against the previous capture. The nightly check: a night's core merges, measured against real spans.
- `social-fix-tracing.sh` — one-shot for a live DeathStarBench socialNetwork namespace: an `otel-collector` ExternalName (SREGym's image exports OTLP gRPC to that bare name, which exists nowhere), the Jaeger sampler set to always-on in every `jaeger-config.yml` ConfigMap (SREGym ships 0.01), and an application restart. The same steps now run inside the smoke deploy.
- `sregym-bench-patch.py` — patches a SREGym checkout for the two arms: `claudecode-base` and `claudecode-neat` agents (no container, so the box's Claude login and NEAT's MCP server on the host are reachable), a per-attempt system-prompt nonce so prompt caching never carries between repeats (it stays on within a session), NEAT wired as an MCP server with an instruction prefix for the neat arm, and the host's Claude credentials seeded per attempt.
- `sregym-overnight.sh` — the overnight smoke run: both arms on each problem, problems taken 2 from every block of 5 in SREGym's order, k=1, manifest + per-attempt timing, then the aggregator.
- `sregym-aggregate.py` — summary.tsv and totals.json per problem and arm: outcomes, wall time, tokens (input, output, cache read, cache write), cost only when prices are given.
- `restart-on-tag.sh` — waits for a published `@neat.is/core` tag, installs core and mcp at that version, restarts the daemon over the source workspace, repairs the bridges, and starts the smoke from problem 1 pinned to the tag.
- `iterate.sh` + `iterate-set.txt` — the 4-to-6-hour iteration run: vanilla versus NEAT, baseline 90 s, propagation 30 s, k=1, on the problems that discriminate (plain agents fail, or NEAT's record was partial).
- `policy-generic-v1.json` — the NEAT arm's policy pack: every compatibility check and a blast-radius warning; committed before any scored attempt, nothing SREGym-specific.
- `neat-record.py` — at agent start, NEAT's whole answer (ask, investigate, root cause, blast radius, graph diff, stale edges, divergences, policies) through one MCP session; measurement only, the agent never sees it.
